Hound Coder

Local LLM stack for coding assistance, used with the Continue extension in VS Code.

Getting access

Access requires a personal API token. Ask an administrator to add you as a user; they can then send you a ready-to-use Continue configuration file (or you can grab it yourself from the admin page if you're an admin).

Setting up Continue

Once you have a config file, open VS Code, install the Continue extension, and replace its configuration (config.yaml) with the one you were given. It points Continue at this server's tab-completion and chat endpoints using your personal token.

Endpoints

  • /tab/ — OpenAI-compatible code completion endpoint
  • /chat/ — OpenAI-compatible chat/agent endpoint
  • /admin/ — admin-only user & token management (requires an admin token)
