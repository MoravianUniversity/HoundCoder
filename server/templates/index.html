Locally hosted LLM stack for coding assistance, exposing separate endpoints for code completion and agent chat. This can be used with several Agents/IDEs with AI support, such as:

  • Zed - both tab-completion and agent chat
  • OpenCode - agent chat only
  • Continue (VS Code extension) - both tab-completion and agent chat

Endpoints

  • /chat/ — OpenAI-compatible chat/agent endpoint (no /v1 prefix)
  • /register/ — self-service registration via Google sign-in{% if allowed_domain %} (@{{ allowed_domain }}){% endif %}
